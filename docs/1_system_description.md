# 1. Опис системи та матриця стейкхолдерів

## 1.1. Загальний опис системи та межі (System Scope)
**E-Commerce Cloud Platform** — це хмарна високонавантажена платформа онлайн-торгівлі, призначена для забезпечення купівлі-продажу товарів у режимі реального часу.

### Основні бізнес-цілі:
1. Забезпечити можливість одночасної обслуги понад 100 000 активних користувачів у період пікових продажів (Black Friday).
2. Скоротити час обробки замовлення від кліка до передачі в службу доставки до < 2 секунд.
3. Забезпечити високу доступність системи (SLA 99.9%).



## 1.2. Матриця стейкхолдерів та їх занепокоєнь (ISO 42010:2022)

| Роль стейкхолдера | Представник | Ключові занепокоєння (Concerns) | Вплив на архітектуру |
| :--- | :--- | :--- | :--- |
| **End User** | Покупець маркетплейсу | Швидкість відповіді (< 1с), доступність 24/7, безпека платіжних даних, зручність UI. | Висуває суворі вимоги до Latency, Usability та Availability. |
| **Business Owner** | CEO / Інвестор | Вартість володіння інфраструктурою, Time-to-Market, масштабованість бізнесу. | Визначає обмеження бюджету, Cloud-Native стратегію та вимоги до Scalability. |
| **DevOps / SysAdmin** | SRE / Інженер підтримки | Зручність моніторингу, CI/CD, автомасштабування, швидка локалізація збоїв. | Висуває вимоги до Observability, Deployability, Fault Tolerance. |
| **Security Officer** | CISO / Фахівець з безпеки | Захист персональних даних (GDPR), відповідність PCI-DSS, запобігання DDoS-атакам. | Висуває вимоги до використання TLS 1.3, OAuth2/OIDC, шифрування даних та Audit Logs. |
| **Software Developer** | Lead Backend / Frontend Dev | Зрозумілість коду, модульність, простота проведення тестування, відсутність дублювання. | Висуває вимоги до Maintainability, Modularity, Testability та Clean Architecture. |
