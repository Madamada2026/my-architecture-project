# 2. Специфікація нефункціональних вимог (NFR) за ISO/IEC 25010:2023

| Категорія (ISO 25010) | Підхарактеристика | Конкретизована нефункціональна вимога | Кількісний індикатор / Метрика |
| :--- | :--- | :--- | :--- |
| **Performance Efficiency** | Time Behaviour | Швидкість пошуку та видачі результатів у каталозі товарів. | Latency p95 ≤ 150 ms при навантаженні 1 000 RPS. |
| **Performance Efficiency** | Capacity | Пропускна здатність системи під час пикових розпродажів. | Система має витримувати пиково 3 000 RPS створення замовлень без помилок 5xx. |
| **Reliability** | Availability | Безперервна доступність сервісів маркетплейсу для користувачів. | SLA = 99.9% (допустимий простій не більше 8.76 годин на рік). |
| **Security** | Confidentiality | Захист персональних даних користувачів та платіжних токенів. | Шифрування Sensitive Data в БД за допомогою AES-256; TLS 1.3 для даних у русі. |
| **Maintainability** | Testability | Автоматичне покриття бізнес-логіки автотестами для запобігання регресії. | Покриття доменної логіки (Domain/Use Cases) юніт-тестами ≥ 80%. |
| **Flexibility** | Scalability | Горизонтальне масштабування компонентів обробки замовлень. | Автомасштабування (HPA) додаткових контейнерів при споживанні CPU > 70% протягом 2 хв. |
